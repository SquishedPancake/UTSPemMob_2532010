# UTS Pemrograman Mobile (React Native / Expo)

## Structure
- `App.js` – main screen; renders `InfoCard` twice and the student directory
- `src/components/InfoCard.js` – Question 1 (reusable card with `title`, `status`, `onPress`)
- `src/screens/StudentDirectory.js` – Question 2 (TextInput + FlatList real-time filter)

## Run
```
npm install
npx expo start
```
Scan the QR code with Expo Go, or press `a` (Android) / `w` (web).
